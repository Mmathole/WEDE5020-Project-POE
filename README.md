  ### Website Goals and Objectives
The websites main goals and objectives are to:
1.	Raise awareness 
•	By educating people about child hunger and the importance of child nutrition in schools.
•	Sharing stories and reports on the impact and the work of the organisation.
2.	Encourage donations and fundraising
•	By providing a clear, simple, secure and transparent online donation system for people.
3.	Engage with its supporters
•	Make it easy for people to contact and support the organisation and bring forth any queries they may have.
•	Create opportunities for volunteers and donors to get involved.
4.	Measure the organisations success
•	Tracking the number of donations that were made online and monitoring website traffic.
5.	Ensuring that the website is easily accessible and easy to navigate for all users
•	Use clear menus and layouts for quick access to information.

### Key Features and Functionality
•	The Homepage includes statistics on their impact and donation.
•	About Us – includes history, mission and patron
•	Why nutrition – educates viewers on the importance of nutrition in school children.
•	Mission – Gives users a better understanding if the organization

### Changelog

This changelog summarizes the main website, security, and documentation improvements made during the project.

### Website structure and content
- Built a multi-page website with Home, About, Programs, Donate, Contact, and Enquiries pages, linked through a consistent navigation menu and footer.
- Added information about the organization, its history, mission, values, team, school feeding work, community outreach, advocacy, and ways to get involved.
- Added donation information and suggested amounts. The donation page is informational and does not process payments.
- Improved page titles, descriptions, canonical links, and image descriptions for clearer browser, search, and assistive-technology support.
- Replaced the site logo and selected photographs with optimized image files, and added image size and loading hints where appropriate.
- Added plain-language comments to explain the purpose of important sections in the website files.

### Design and interactive features
- Improved shared colors, typography, layouts, buttons, cards, and responsive styles for desktop, tablet, and mobile screens.
- Added an expandable history section, accessible vision/mission/values tabs, a regional map, and an image gallery with a keyboard-friendly lightbox to the About page.
- Added program search, focus filtering, alphabetical sorting, and a message when no programs match.
- Added topic-specific enquiry fields and immediate answers to common questions, with links to relevant pages.

### Forms and server
- Added contact and enquiry forms with browser and server-side checks for required fields, email addresses, phone numbers, message lengths, enquiry topics, and topic-specific choices.
- Added form feedback for validation, sending, success, and failure, plus a hidden spam-trap field.
- Added a Node.js service that serves an allowlist of public files and can send validated form submissions through Nodemailer when correctly configured.
- Added request-size limits, per-address submission limits, origin and content-type checks, and server request timeouts.
- Documented that GitHub Pages cannot run the Node.js mail service: on the published static site, visitors must open, review, and send an email draft themselves.

### Security and accessibility
- Added restrictive Content Security Policies and browser security headers where the hosting platform supports them.
- Restricted external resources to the Leaflet files needed by the map, and added Subresource Integrity checks to those files.
- Improved keyboard operation, focus behavior, labels, accessible names, live status messages, and reduced-motion support for interactive features.

### Publishing and project documentation
- Added a GitHub Actions workflow to publish an explicit allowlist of public website files to GitHub Pages.
- Kept project materials and server-side configuration out of the Pages publishing artifact.
- Updated project references and added links to media coverage and fundraising initiatives involving The Lunchbox Fund.
- Added setup and publishing instructions, including required mail-server settings and GitHub Pages form limitations.

### Backlinks

Several external websites help promote The Lunchbox Fund by mentioning the organization and linking it to its website. For example, Bizcommunity published an article about Shoprite's World Food Day initiative that included a link to The Lunchbox Fund. Discovery Limited also published an article about a charity campaign by Saray Khumalo and Sibusiso Vilane, which linked directly to the organization's donation page. The citizen published a similar article containing a link to the donation page. These examples demonstrate how path links from news and business websites can increase awareness, direct visitors to the organization's website and improve its online visibility.
